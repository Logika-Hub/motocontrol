# Manual do MotoControl

O MotoControl organiza o dia a dia da oficina em torno da **comanda** (ordem de serviço): cada moto que entra recebe uma comanda, e tudo o que acontece com ela — diagnóstico, serviços, peças, mudanças de situação — fica registrado com o nome de quem fez e o horário.

> Este manual também está disponível dentro do sistema, no botão **Ajuda** no canto superior direito.

## O fluxo de uma moto na oficina

```
 Cliente chega       Mecânico avalia       Faltou peça?          Mecânico trabalha      Moto pronta
 ─────────────►  ───────────────────►  ───────────────────►  ───────────────────►  ─────────────►
   ABERTA           EM DIAGNÓSTICO        AGUARDANDO PEÇAS        EM EXECUÇÃO           CONCLUÍDA
 (atendente abre)  (registra o problema)  (opcional)            (marca serviços feitos) (impressão e assinatura)
```

A qualquer momento antes de concluir, a comanda pode ser **cancelada** (com justificativa).
